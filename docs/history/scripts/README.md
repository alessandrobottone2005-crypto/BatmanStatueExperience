# Pipeline storiche ritirate

Questi tre script appartengono a precedenti esportazioni di immagini e video. Usano sequenze sorgente assenti o percorsi locali di applicazioni; non sono supportati dalla struttura corrente e non vanno eseguiti per pubblicare il sito.

Gli MP4 e gli 800 WebP correnti sono conservati in public. Per rigenerare i JPG di fallback usare `node scripts/extract-frame.mjs` dalla root; per la build e i test usare i comandi del README principale.
