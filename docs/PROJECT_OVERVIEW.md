# Panoramica

Progetto accademico desktop di Alessandro Bottone, dedicato a Batman 87th Anniversary. Unisce una missione a tempo nella Batcaverna, una sequenza statua di 800 frame e un checkout locale simulato.

Le scelte e i comandi correnti sono nel README. Le precedenti specifiche e il vecchio changelog sono in `history`; non costituiscono requisiti implementati o prove di performance attuale.
